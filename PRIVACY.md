# Privacy Policy

Melio is an iPhone client for **your** Jellyfin server. Melio does not run a backend, does not create accounts, and does not sell or share personal data.

**What Melio stores on this device**

- The server address and a session token for servers you add
- Optional downloads, lyrics, and a local catalog cache so you can listen offline

That material stays on the device. Melio does not upload your library, tokens, or listening history to Melio.

**What Melio talks to**

- The Jellyfin server URL you enter (playback, library, sign-in, including SSO in the system browser if your server uses it)
- Speakers on your local network when you use AirPlay or Chromecast

Melio uses Local Network and Bonjour only to reach that server on a LAN and to find speakers. There is no Melio analytics SDK, advertising, or tracking.

**Your Jellyfin account**

Sign-in is the user you already have on Jellyfin. Forgetting a server or signing out in Melio only removes the saved login and cached files from this iPhone. It does not delete your Jellyfin user. Manage or delete that user on your Jellyfin server.

**Questions**

Open an issue on [github.com/kgrubb/melio](https://github.com/kgrubb/melio).
